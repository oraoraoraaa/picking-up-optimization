# `resource/docs`

Store documentation assets that are referenced by markdown or technical docs in this folder.

## What to put here

- Diagrams and architecture visuals
- Flowcharts and screenshots used in docs
- PDF or SVG supporting materials

## Naming Convention

Use this pattern for every file:

<project>-<doc-topic>-<asset-type>-v<major>.<ext>

Rules:

- Use lowercase letters only
- Use hyphens between words
- Do not use spaces or underscores
- Keep names short but descriptive
- Increment major version when replacing a published asset

Examples:

- pickup-op-routing-diagram-v1.svg
- pickup-op-setup-screenshot-v3.png
