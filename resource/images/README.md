# `resource/images`

Store general image assets that do not belong in banners or icons.

## What to put here

- Product screenshots and reference images
- Backgrounds, textures, and supporting visuals
- Optimized exports for web or docs

## Naming Convention

Use this pattern for every file:

<variant>_v<major>.<ext>

Rules:

- Use lowercase letters only
- Use hyphens between words
- Do not use spaces or underscores
- Keep names short but descriptive
- Increment major version when replacing a published asset

Examples:

- dashboard_overview_v1.png
- route_preview_mobile_v2.jpg
