# `resource/icons`

Store icon assets used by applications, documentation, and branding in this folder.

## What to put here

- App icons and launcher icons
- Feature or status icons
- Exported icon sets by size or platform

## Naming Convention

Use this pattern for every file:

<project>-<icon-name>-<size-or-platform>-v<major>.<ext>

Rules:

- Use lowercase letters only
- Use hyphens between words
- Do not use spaces or underscores
- Keep names short but descriptive
- Increment major version when replacing a published asset

Examples:

- pickup-op-navigation-24px-v1.svg
- pickup-op-notification-android-v2.png
