# Resource

Use this directory to store resources such as images, banners, and similar files.

## Contributor Rule

Before adding, renaming, moving, or replacing any file, read the README.md in the target sub-directory first.

Each sub-directory README defines:

- What resource types belong in that folder
- The required naming convention
- Example filenames

If an appropriate category folder does not exist, create a new one for your resources and add a README.md that follows the same guidance style.
