# Resource/banners

Store banner assets for docs, web pages, and promotional content in this folder.

## What to put here

- Horizontal and vertical banner images
- Hero graphics and section headers
- Export-ready source variants when needed

## Naming Convention

Use this pattern for every file:

<project>-<feature>-<variant>-v<major>.<ext>

Rules:

- Use lowercase letters only
- Use hyphens between words
- Do not use spaces or underscores
- Keep names short but descriptive
- Increment major version when replacing a published asset

Examples:

- pickup-op-home-hero-v1.png
- pickup-op-release-header-v2.webp
